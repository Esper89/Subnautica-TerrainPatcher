Terrain Patch Format

This is the format specification for Subnautica terrain patches, also known as the optoctreepatch format. This format is based on the Subnautica terrain data format (version 4), and understanding that is recommended to use this format.

Primitive types are written using conventions from C#. For example, uint is an unsigned 32-bit integer, short is a signed 16-bit integer, and byte[] is a variable-sized array of unsigned 8-bit integers. All primitive types used in the terrain patch format are little-endian, and signed integer types use two's complement.

Format

Byte 0 1 2 3 …
Field Version Terrain Patch
Type uint

The first four bytes of each optoctreepatch file are an unsigned 32-bit integer that encodes the format version. The current version is 0. If the version is 4 294 967 295 (the maximum value of an unsigned 32-bit integer) then the patch is guaranteed to be invalid and will be ignored. The remaining bytes of the file are specified at v0.

Naming

Patch files must use the .optoctreepatch file extension. The file name should be the name of the mod that includes the terrain patch, or (if the mod contains multiple terrain patches) a short description of the contents of the patch.

Patch names should prefer to use lowercase letters, numbers, and hyphens. For example, void-bottom.optoctreepatch and distant-islands-3.optoctreepatch are good names for terrain patches.

There is no need for patch files to contain words like “terrain” or “patch” unless they're part of your mod's name.
